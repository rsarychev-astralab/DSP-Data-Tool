# Инструкция: преобразование данных DSP

Утилита переводит **выгрузку от DSP-партнёра** (Excel) в **шаблон загрузки** для реестра. При необходимости второй шаг — **метчинг договоров** с внутренней базой (ERID, ID в OTM / OZON / VK).

**Адрес сервиса:** https://dsp.belyauskas.ru:8443  
(обязательно порт **8443** в адресной строке)

Для вкладки проверки юрлиц нужен ключ DaData на сервере (`DADATA_API_KEY`).

---

## Что понадобится

- Браузер (Chrome, Firefox, Edge).
- Файл выгрузки от DSP: `.xlsx`, `.xlsm` или `.xls`, не больше **50 МБ**.
- Знание **DSP-партнёра** и **отчётного месяца**.

---

## Общая схема работы

```
Выгрузка DSP  →  [Преобразование]  →  Шаблон загрузки (.xlsx)
                                              ↓
                                    [Сопоставление договоров]  →  Файл с ID (.xlsx)
```

Обычно достаточно **первой вкладки**. Метчинг нужен, когда требуются внутренние идентификаторы по договорам.

---

## Вкладка «Преобразование выгрузки»

Вверху формы — индикатор шагов: **DSP → Файл → Обработка → Скачать**. Активный шаг подсвечен синим, пройденные — зелёным.

### 1. Выберите DSP

1. В поле **DSP** начните вводить название партнёра.
2. Выберите нужный пункт **из выпадающего списка** (нельзя просто напечатать название и не выбрать).
3. После выбора появится блок **«Данные из справочника»**:
   - номер договора;
   - отчитываемся в ОРД (да/нет);
   - ссылка на сайт DSP;
   - статус: **«Преобразование доступно»** или **«Профиль не настроен»**.

| Статус | Что это значит |
|--------|----------------|
| **Преобразование доступно** | Можно загружать файл и нажимать «Преобразовать». |
| **Профиль не настроен** | Для этого DSP ещё не настроен маппинг полей. См. раздел [Новый DSP без профиля](#новый-dsp-без-профиля). |

Если в справочнике нет договора — в карточке будет «—». На преобразование это обычно не влияет.

### 2. Укажите отчётный период

Выберите **месяц** и **год** отчёта. Под полями появится подсказка с именем будущего файла, например:

`otm_jun_2026.xlsx`

Имя формируется автоматически: `{dsp}_{месяц}_{год}.xlsx`.

### 3. Загрузите файл выгрузки

- Нажмите на область **«Файл выгрузки»** или перетащите файл мышью.
- Допустимые форматы: `.xlsx`, `.xlsm`, `.xls`.
- Чтобы убрать файл — кнопка ✕ справа от имени.

### 4. Нажмите «Преобразовать»

Кнопка активна, когда выбран DSP **с настроенным профилем** и загружен файл.

Во время обработки:

- показывается **полоса прогресса** (загрузка → обработка на сервере → скачивание результата);
- кнопка временно недоступна.

### 5. Скачайте результат

После успешной обработки:

1. **«Скачать файл»** — готовый шаблон загрузки DSP (21 колонка).
2. При замечаниях проверки — **«Скачать файл замечаний»** (отдельный Excel с логом ошибок по строкам).

Под кнопками — краткая сводка: сколько строк записано, сколько пустых строк пропущено, время обработки.

#### Замечания проверки шаблона

Это **не всегда блокирует скачивание**. Файл результата обычно можно скачать и посмотреть замечания:

- в зелёном блоке под кнопками (краткий список);
- в **файле замечаний** (полный список по строкам Excel).

Типичные замечания: пустые обязательные поля, некорректный тип договора, ИНН и т.п. Исправьте данные в исходной выгрузке или в полученном файле и при необходимости запустите преобразование снова.

## Вкладка «Сопоставление договоров»

Используйте **после** преобразования на первой вкладке.

### Что делает метчинг

Сопоставляет строки из **готового шаблона загрузки** с **базой договоров** по полям:

- номер, дата, тип и предмет договора;
- ИНН заказчика и исполнителя.

В номере договора в базе часто есть суффикс вида ` - 1234` (внутренний id) — при сравнении он отбрасывается.

**На выходе** в файле два листа:

| Лист | Содержимое |
|------|------------|
| **ID** | Краткая таблица: ERID и ID в OTM, OZON, VK |
| **Выгрузка с ID** | Основные поля договора и сторон + те же ID |

### Как выполнить метчинг

1. Откройте вкладку **«Сопоставление договоров»**.
2. Убедитесь, что вверху зелёное сообщение о загруженной **базе договоров** (`База договоров.xlsx`). Если база не найдена — метчинг недоступен (обратитесь к администратору).
3. Загрузите **тот же файл**, который скачали после преобразования (шаблон загрузки DSP).
4. Нажмите **«Сметчить»**.
5. Скачайте **«Сметченный файл»**.

В сводке будет: сколько строк ERID, сколько договоров сметчено, сколько без пары (у них ID останутся пустыми).

## Вкладка «Проверка юридических лиц»

Проверка организаций и ИП через DaData: одна карточка или массовая выгрузка из файла.

Если сверху жёлтое предупреждение про ключ `DADATA_API_KEY` - проверка недоступна, нужен ключ в окружении сервера.

### Разовая проверка

1. Откройте вкладку **«Проверка юридических лиц»**.
2. Введите ИНН (10 или 12 цифр) или название.
3. Выберите подсказку или нажмите **«Проверить»**.
4. В карточке: статус, ОГРН, КПП, ОКВЭД, руководитель, адрес.

### Массовая проверка

1. Переключитесь на **«Массовая проверка»**.
2. Загрузите файл `.xlsx` / `.xls` / `.csv` / `.txt` / `.tsv` с ИНН (колонка `ИНН` или список).
3. Выберите формат результата (по умолчанию как у входного файла).
4. Нажмите **«Проверить и скачать»**.

Ограничения: до 2000 уникальных ИНН, файл до 5 МБ. Если DaData упрётся в лимит, скачается частичный результат.

## Новый DSP без профиля

Если у партнёра статус **«Профиль не настроен»**:

1. Выберите DSP из списка.
2. Загрузите **образец выгрузки** этого партнёра.
3. Нажмите **«Сохранить маппинг полей»** (вместо «Преобразовать»).

Файл сохранится для настройки маппинга разработчиком. После настройки профиля статус сменится на **«Преобразование доступно»** — тогда можно работать как обычно.

## Частые ошибки и что делать

| Сообщение / ситуация | Причина | Что сделать |
|----------------------|---------|-------------|
| «Выберите DSP из списка» | Название введено, но не выбрано из списка | Кликните по нужному DSP в выпадающем списке |
| «Профиль преобразования не настроен» | Нет маппинга для партнёра | «Сохранить маппинг полей» или дождитесь настройки |
| «Нужен файл .xlsx, .xlsm или .xls» | Неверный формат | Сохраните выгрузку в Excel |
| «Файл больше 50 МБ» | Слишком большой файл | Разбейте период или уточните у DSP |
| «Нет данных для записи» | В файле нет строк с данными | Проверьте лист и период в выгрузке |
| **502 Bad Gateway** | Временный сбой сервера или перегрузка | Обновите страницу (Ctrl+Shift+R) и повторите; если повторяется — напишите администратору |
| Кнопка «Преобразовать» неактивна | Не выбран DSP, нет профиля или не загружен файл | Проверьте все три условия выше |
| В карточке DSP нет договора («—») | В справочнике поле пустое | На преобразование обычно не влияет; договор можно добавить в справочник |

---

## Советы

- **Не закрывайте вкладку** во время обработки больших файлов — дождитесь окончания прогресса.
- **Имя результата** зависит от DSP и периода — сохраняйте файлы в понятную папку сразу после скачивания.
- Для метчинга используйте **свежий** файл после преобразования, а не старую версию.
- Если замечаний много — сначала скачайте **файл замечаний**, исправьте данные, затем повторите преобразование.

---

## К кому обращаться

- **Новый DSP в списке, нет профиля, нет договора в справочнике** — администратор / команда, которая ведёт справочник `Справка/DSP.xlsx` и профили партнёров.
- **Метчинг недоступен** (нет базы договоров) — администратор сервера.
- **502, долгая обработка, ошибки, которых нет в таблице выше** — администратор сервиса с указанием DSP, периода, имени файла и времени ошибки.
