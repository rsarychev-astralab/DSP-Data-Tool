## Именование при маппинге

**ИНН заказчика** и **ИНН исполнителя** — всегда разные поля. Не используй общий ключ `inn`.

| Роль | Колонка | Ключ в record | Типичные входные колонки |
|------|---------|---------------|--------------------------|
| Заказчик (рекламодатель) | J | `customer_inn` | customer_inn, advertiser_inn, client_inn |
| Исполнитель (DSP) | P | `contractor_inn` | contractor_inn, publisher_inn, executor_inn |
| Адрес заказчика | I | `customer_address` | customer_address, advertiser_address, адрес заказчика |
| Адрес исполнителя | O | `contractor_address` | contractor_address, publisher_address, юридический адрес, адрес исполнителя |

Аналогично для наименований: `customer_name` → H, `contractor_name` → N.

## Преобразование vs skip пустых ячеек

| | Преобразуй | Skip (ячейка пустая) |
|---|------------|----------------------|
| **Когда** | Значение есть во входе или явно передано пользователем | `null`, `""`, пробелы, нет колонки, неоднозначный маппинг |
| **На этапе чтения** | Ключ попадает в `record` | Ключ **не добавлять** в `record` |
| **На этапе записи** | `write_cell(ws, row, col, value)` | **Не вызывать** `ws.cell` — ячейка truly empty |
| **Примеры** | `advertiser_inn` → J; «Посредничество» → `Mediation` | Нет `contractor_inn`; не указан тип заказчика; нет адреса |

## Пустые поля (skip)

Нет данных — **skip** на всех этапах. Не используй заглушки, defaults и эвристики.

| Ситуация | Действие |
|----------|----------|
| Колонки нет во входе | Skip |
| Значение `null` / пустая строка / пробелы | Skip |
| Неизвестен тип контрагента | Skip (G или M пустые) |
| Не указан НДС | Skip (S пустая) |
| Нет ИНН исполнителя у партнёра | Skip (P пустая; не копировать ИНН заказчика) |
| Нет адреса заказчика или исполнителя | Skip (I или O пустая) |

## Условная обязательность (* — заказчик, ** — исполнитель)

### Для российских типов (`LegalPerson`, `IndividualEntrepreneur`, `PhysicalPerson`)
- **ИНН обязателен**
- Рег.номер и ОКСМ — необязательны

### Для иностранных типов (`ForeignPhysicalPerson`, `ForeignLegalPerson`)
- **ОКСМ обязателен**
- **ИНН обязателен**, если Рег.номер не заполнен
- **Рег.номер обязателен**, если ИНН не заполнен
- Достаточно заполнить одно из: ИНН или Рег.номер (но хотя бы одно должно быть)

## Нормализация справочников

При преобразовании принимай оба варианта — английский код и русское название. В выходной файл записывай **то значение, которое уже используется в эталонных данных пользователя**; если эталона нет — предпочитай **английский код**.

### Тип договора (D)
| Код | Русское |
|-----|---------|
| Intermediary | Посреднический |
| Additional | Дополнительное соглашение |
| Original | Оказание услуг |

### Предмет договора (E)
| Код | Русское |
|-----|---------|
| Representation | Представительство |
| Distribution | Договор на распространение рекламы |
| DistributionOrganization | Договор на организацию распространения рекламы |
| Mediation | Посредничество |
| Other | Иное / Другое |

### Вид деятельности (F)
| Код | Русское |
|-----|---------|
| Conclude | Заключение договоров |
| Distribution | Действия в целях распространения рекламы |
| Commercial | Коммерческое представительство |
| Other | Иное / Другое |
| None | нет |

### Тип контрагента (G, M)
| Код | Описание |
|-----|----------|
| LegalPerson | Юридическое лицо |
| IndividualEntrepreneur | ИП |
| PhysicalPerson | Физическое лицо |
| ForeignPhysicalPerson | Иностранное физлицо |
| ForeignLegalPerson | Иностранное юрлицо |

**Внимание:** `Distribution` в колонке E = «Договор на распространение рекламы»; в колонке F = «Действия в целях распространения рекламы». Не путать при нормализации.

### Включая НДС (S)
| Значение | Смысл |
|----------|-------|
| yes | Сумма указана с НДС |
| no | Сумма указана без НДС |

Нормализация справочника — **только если значение уже есть во входе**. Пустое поле — **skip**, не заполняй предпочитаемым кодом.
