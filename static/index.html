    Замечания проверки шаблона

      Сначала преобразуйте выгрузку на соседней вкладке, затем загрузите тот же файл результата (шаблон загрузки DSP, 19 колонок). Метчинг по договору: номер, дата, тип и предмет договора, ИНН заказчика и исполнителя. В базе у номера часто суффикс « - 1234» (внутренний id) — при метче он отбрасывается. На выходе — ERID и ID в OTM, OZON, VK. В файле два листа: ID (краткий) и Выгрузка с ID (основные поля договора/сторон + ID).
