# UI

## Выбранная библиотека: **Bootstrap 5**

Ориентир по стилю: [ЕРИР (erir.grfc.ru)](https://erir.grfc.ru/) — официальный портал реестра (ГРЧЦ).

Почему Bootstrap, а не React-библиотеки:

| Критерий | Bootstrap 5 | Ant Design / MUI |
|----------|---------------|------------------|
| Стек проекта | один `index.html` + FastAPI | нужен React/Vue и сборка |
| Похожие гос./реестровые сайты РФ | часто Bootstrap или его производные | реже на публичных формах |
| Кастомизация цветов | CSS-переменные `--bs-primary` | тема в JS |
| Combobox, формы, алерты | из коробки | из коробки |

Иконки: **Bootstrap Icons 1.11** (CDN `bootstrap-icons.min.css`), без отдельной сборки.

## Тема (приближение к ЕРИР)

- Шрифт: **PT Sans** (типичен для русскоязычных гос. интерфейсов)
- Primary: `#1a4a7a`, шапка: `#153d66`
- Фон: `#eef1f6`, карточки с лёгкой рамкой
- Скругление: 4px (сдержанное, не «стартап»)

При доступе к живому erir.grfc.ru можно уточнить hex-коды из DevTools и подставить в `:root` в `index.html`.

## Альтернативы

- **Tabler** — если понадобится «кабинет» с сайдбаром (на базе Bootstrap).
- **Ant Design** — если позже будет SPA на React и корпоративный UI как у внутренних систем операторов.
